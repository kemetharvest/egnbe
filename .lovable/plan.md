# خطة التنفيذ

## ١. إعادة تصميم الصفحة الرئيسية (`src/routes/index.tsx`)
أعيد بناء الصفحة بنفس ستايل الصور المرفقة:
- بطاقات كبيرة عمودية (Card Stack) واحدة تحت التانية بدل الجريد الأفقي.
- كل بطاقة: صورة كبيرة في الأعلى + شارة زرقاء "⭐ ..." في الزاوية + عنوان عريض + وصف رمادي + زر أزرق ممتد بعرض البطاقة مع سهم ←.
- البطاقات بالترتيب:
  1. **الساعة الذكية** — شارة "عرض حصري" — زر "اطلب الآن" → يحوّل لصفحة `/watches` الجديدة.
  2. **تفعيل البطاقة** — شارة "آمن وسريع" — زر "سجّل الآن" → `/login`.
  3. **الجائزة الكبرى** — شارة "السحب الكبير" — زر "شارك الآن" → `/login`.
  4. **جوائز شهرية** — شارة "سحب شهري" — زر "شارك الآن" → `/login`.
- ألوان الأزرار/الشارات: الأزرق الكحلي الموجود في الـ design tokens (primary).
- الهيدر يفضل زي ما هو (لوجو + English).

## ٢. صفحة اختيار الساعات الجديدة (`src/routes/watches.tsx`)
- مسار جديد `/watches` بعنوان "اختر لون ساعتك".
- جريد بـ ٦ ساعات (٢ أعمدة موبايل / ٣ أعمدة ديسكتوب).
- ٦ ألوان: روز جولد، ميدنايت، فضي، جولد، أزرق، أخضر (هستخدم الـ ٣ صور الموجودة + توليد ٣ صور إضافية بـ imagegen للألوان الناقصة).
- كل كارت: صورة + اسم اللون + وصف قصير، وعند الضغط يحوّل لـ `/login`.
- نفس لغة التصميم (بطاقات بحدود ناعمة، ظل خفيف، hover يرفع الكارت).

## ٣. ملاحظات تقنية
- استخدام `<Link to="/watches">` و `<Link to="/login">` (type-safe routing).
- صور الساعات الجديدة تتولّد في `src/assets/` بصيغة jpg.
- بدون أي تغيير في الباك إند أو منطق الـ admin/login/otp.
- الـ route الجديد هيتسجّل أوتوماتيكياً في `routeTree.gen.ts`.
